# Security policy

Dot.docs is part of the InfoDot ecosystem and follows InfoDot's vulnerability disclosure policy:
<https://infodot.co.za/security>.

**Report a vulnerability** privately to **privacy@infodot.co.za** (also published at
`https://doc.infodot.co.za/.well-known/security.txt`). Please do not open a public GitHub issue for a security problem.
Include the affected address, steps to reproduce, and what an attacker could do.

What to expect: an acknowledgement within a few working days, a fix prioritised by severity, and credit if you want it.
Please give us reasonable time to fix before publishing, and do not access, change or delete other people's data while testing.

Supported version: the `main` branch, which is what runs at doc.infodot.co.za.
